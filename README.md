# Ecommerce-Sales-Power-BI_Analysis
# E-Commerce Sales Dashboard | Power BI

## Project Overview
Interactive Power BI dashboard created to analyze e-commerce sales, profit, orders, quantity, categories, states, monthly trends and payment modes.

## Tools Used
- Power BI
- Power Query
- DAX

## Data Model
- **Orders Table** – Order ID, Order Date, Customer Name, State, City
- **Details Table** – Order ID, Amount, Profit, Quantity, Category, Sub-Category, Payment Mode
- Connected both tables in **Model View using Order ID**.

## Data Preparation
- Removed duplicates and unnecessary rows
- Corrected data types
- Fixed Order Date using locale
- Prepared data for analysis using Power Query

## Dashboard Highlights
- Total Revenue
- Total Profit
- Total Quantity
- Total Orders
- Revenue & Profit by Category
- Profit by State
- Monthly Revenue Trend
- Payment Mode Analysis
- Quantity by Sub-Category
- Interactive Category Filter

## Objective
To transform raw e-commerce data into an interactive dashboard for quick and easy business analysis.
